## HyperCreator 核心知识

**定位：** 不卖 AI 工具，交付审美价值与生意增长的确定性。技术易得，品味难求。

**核心壁垒：** 视觉一致性误差<3% | 良品率90%+直接商用 | 品牌调性一致度95%+ | 降本90%+（单张≈4.5元）| 零门槛操作

**双引擎：** HyperInsight（解决"说什么"）+ HyperCreator（解决"长得像、说得准、直接用"）

**差异化：** 不是 C 端抽卡工具，是 B 端企业视觉工厂——确定性、规模化、可预测商业价值。

## BD 方法论

> 详细手册见 `reference/bd-playbook.md`，包含画像模板、搜索策略、性格分析框架、邮件生成规范。

**核心原则：**

- **目标客户：** 50-500人中型美妆/彩妆/香氛品牌，有出海需求，决策层
- **流程：** 分批搜索 → LinkedIn/Web 搜索 → 性格画像 → 个性化邮件生成
- **发送策略：** 先 LinkedIn 连接 → 无权限再发邮件；工作日 9-11AM
- **邮件只生成不发送**，等主人确认

## 反复出现的模式

- 大规模 Key Person 挖掘（100+）→ 分批执行、中途保存
- 邮件生成 → 记忆 → 确认 → 发送（不自动发）
- 多语言版本：英文 + 中文 + LinkedIn 版
- 性格分析先于 outreach
