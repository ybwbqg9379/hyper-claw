# HEARTBEAT.md — 心跳检查清单

## 每次心跳执行以下检查

### 1. 待办事项提醒

- 优先使用 `memory_get` 检查当天 `memory/YYYY-MM-DD.md` 中是否有未完成的 TODO 项
- 若当天日志不存在，视为“今天尚无日志”，不要报错
- 如果有即将到期（< 24h）的任务，主动提醒主人

### 2. 记忆维护（每 3 天执行一次）

- 优先使用 `memory_get` 阅读最近 3 天的每日日志
- 若某一天的日志不存在，按空内容继续，不要因为缺文件中断
- 将关键经验蒸馏到 `MEMORY.md`
- 清理 `MEMORY.md` 中过时的条目
- 检查 `MEMORY.md` 总字数是否超过 5000 字

### 3. Gateway 健康

- 如果有异常日志或连接问题的迹象，提醒主人检查

### 4. BD Pipeline 进度

- 检查 `memory/` 中近期的 Key Person 搜索记录
- 如有未完成的画像分析或邮件生成，提醒主人
- 汇报 pipeline 统计（已搜索/已画像/已生成邮件/待处理）

## 静默条件

以下情况直接回复 `HEARTBEAT_OK`：

- 深夜时段（23:00 - 08:00 PST），除非有紧急事项
- 上次检查后没有任何新内容
- 所有检查项均正常
